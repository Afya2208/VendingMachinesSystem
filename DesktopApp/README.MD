# VendingMachinesSystem Desktop
Это настольное приложение на Avalonia личного кабинета франчайзера для управления информацией о вендинговых торговых автоматах и компаниях-партнерах. 

На главной странице отображаются диаграммы и аналитика по состоянию ТА, продажам, сводка статистики и новостей.

В разделе Торговые автоматы выводится таблица ТА, данные можно менять и добавлять через форму добавления и редактирования ТА. Также информацию о ТА можно экспортировать в 3 формата: .pdf, .csv, .html. На странице есть пагинация, поиск по номеру и названию ТА, смена отображения на плитку/таблицу

В разделе Компании выводится таблица компаний, данные можно менять и добавлять через форму добавления и редактирования компаний. Также информацию о компаниях можно экспортировать в 3 формата: .pdf, .csv, .html. На странице есть пагинация, поиск по названию и адресу компаний, смена отображения на плитку/таблицу

Требует подключение к Web-API VendingMachinesSystem, настройка пути к Web-API находится в файле appsettings.json

Проект пока в процессе разработки и переписывается старый код. Планируется сделать:
- Мониторинг ТА

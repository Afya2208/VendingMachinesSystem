
# VendingMachinesSystem MobileApp
Это мобильное приложение на Kotlin для обслуживающего персонала торговых автоматов для создания отчетов по работе и написания заметок.

Проект в процессе разработки:
- Авторизация инженера, восстановление пароля по почте
- Раздел заданий/заказов на обслуживание
- Фото и видеосъемка работы до и после, сохранение данных в отчеты
- Редактор фото: обрезка, поворот, рисование маркером, добавление аннотации к фото
- Создание заметок - текстовый редактор, возможность прикрепить фото из галереи, голосовой ввод
